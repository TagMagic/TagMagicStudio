Quick Start Guide

1. Get Your API Key
Sign up for any plan

Copy your API key from your dashboard

Add it to every request using:
Authorization: Bearer YOUR_API_KEY

2. Prepare Your Request
Use POST /v1/tag

Send audio file as binary or multipart/form‑data

Supported formats: MP3, FLAC, WAV

3. Send Your First File
Upload your audio file

API extracts metadata

Developer & Pro plans also update album art automatically

4. Read the JSON Response
You’ll receive fields like:

• title

• artist

• album

• genre

• year

• track

• comments

• artwork (Developer & Pro)

5. Handle Errors

• 400 → invalid request

• 401 → missing/invalid API key

• 429 → rate limit exceeded

• 500 → server error

6. Move to Production
Switch to Developer or Pro

Use batch workflows

Monitor usage

Integrate into automation pipelines

FAQ+Troubleshooting

 • FAQ
Does TagMagicAPI store my files?
No. Files are processed instantly and never saved

Does the Free Plan include album art updating?
No. Only Developer and Pro plans include artwork updating

What audio formats are supported?
MP3, FLAC, WAV

How do I authenticate?
Add your API key to the header:
Authorization: Bearer YOUR_API_KEY

Is album art included in the JSON response?
Yes — Developer and Pro plans return updated artwork

Can I use TagMagicAPI commercially?
Yes. Developer and Pro plans allow commercial use

Does TagMagicAPI modify my original file?
No. Your original file remains unchanged

What happens if I exceed my daily limit?
You’ll receive a 429 Too Many Requests response


• Troubleshooting
400 — Bad Request
File missing or unreadable

Unsupported format

Fix: Ensure MP3/FLAC/WAV and valid binary upload

401 — Unauthorized
Missing or invalid API key

Fix: Confirm header is set correctly

429 — Rate Limit Exceeded
Daily limit reached

Fix: Wait for reset or upgrade plan

500 — Server Error
Unexpected processing issue

Fix: Retry the request; check file integrity

Metadata Missing or Null
Some files contain incomplete tags

Fix: Use Developer/Pro for artwork updating and extended tag support

Artwork Not Returned
Free plan does not include artwork

Fix: Upgrade to Developer or Pro

Slow Response Times
Large files or high traffic

Fix: Developer/Pro plans have faster routing
