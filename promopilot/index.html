    Getting Started

    1. Get your Claude API key (one time)

    1. Go to console.anthropic.com and sign up or sign in.
    2. Click Billing and add a small amount of credit, like $5 or $10.
    3. Click API Keys, then Create Key. Name it PromoPilot.
    4. Copy the key right away (it starts with sk-ant-). It is only shown once.
    5. Back here, click ⚙️ Settings, paste the key, click 🔌 Test Key, then Save Settings.

    2. Promote a product

    1. Click ➕ Add a Product and fill in what it is and who it's for.
    2. Pick the product, tick the kinds of posts you want, and click ✨ Create.
    3. Use 📋 Copy to copy a post, then paste it on Pinterest, Reddit, Facebook and so on yourself.
    4. Everything you create is kept under Saved for that product.
    5. Use Ask PromoPilot for questions like "Which subreddit should I post DroidMirrorMagic in first?"

    Keep your key private. Anyone with it can spend your API credit. If it ever gets out, delete it in the console and make a new one.
